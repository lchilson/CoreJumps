# C# Lesson Sequence

Teach in this order:

1. Variables and values
2. Conditions
3. Loops
4. Methods and parameters
5. Return values
6. Classes and objects
7. Properties and constructors
8. Enum and static helper
9. Interface
10. Inheritance
11. Testing

Do not teach patterns before the learner understands state and behavior.

## Good questions

- What data is changing?
- What is the input?
- What is the output?
- Why does this object need this state?
- What happens when we create a second instance?
