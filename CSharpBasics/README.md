-# CSharpBasics

This is a compact C# exercise project for a product catalog. Keep it simple.

Use it in this order:

1. Variables and values
2. Conditions and loops
3. Methods and parameters
4. Class and object state
5. Properties and constructors
6. Enum and static helper
7. Interface and abstraction
8. Inheritance and override
9. Testing

Do not read everything at once. The full demo is a reference, not the lesson plan.

## Run it

```powershell
dotnet run --project CSharpBasics
```

## Files

- `Program.cs` — demo showing multiple C# ideas together
- `Product.cs` — class with fields, properties, constructor, methods
- `Enums.cs` — enum example
- `StaticExamples.cs` — static helper example
- `Interfaces.cs` — interface example
- `Inheritance.cs` — inheritance example
